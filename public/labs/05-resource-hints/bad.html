Без hints — все стартує пізно

Google Fonts inject-иться JS після blocking script (~8 s). Preload scanner цей шрифт не бачить — CSS зʼявляється лише після parser-blocking.js.

  1. Network → Disable cache → Hard reload.
  2. Поки parser-blocking.js?delay=8000 pending — переконайся, що немає запитів до fonts.googleapis.com і gstatic.
  3. Після script: зʼявляється CSS → потім .woff2. На .woff2 → Timing → має бути DNS Lookup.
  4. Порівняй з better.html (DNS) і best.html (preload).
