DNS hint готує hostname заздалегідь

Той самий JS inject, що в bad.html, плюс dns-prefetch у <head>. CSS як і раніше стартує лише після blocking script — різниця в DNS на .woff2.

  1. chrome://net-internals/#dns → Clear host cache.
  2. Спочатку bad.html → фільтр gstatic → Timing на .woff2 → зафіксуй DNS Lookup.
  3. Clear host cache знову → better.html → той самий .woff2 → DNS Lookup має бути відсутнім або ~0 ms.
  4. CSS під час pending script у обох однаковий (немає) — порівнюй саме DNS, не Start CSS.
